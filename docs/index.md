# 关于这组文章

这组文章讨论科技整合包里很实际的问题：玩家为什么愿意花时间做一台机器？什么样的流程会让人觉得有进步，什么样的流程只是多跑几趟？一条产线做完之后，后面还会不会用到？

可以从[科技整合包的路线，应该怎么设计](/route-principles)开始，再看配方图、四象限、机器分工和自动化。每篇都能单独读，合起来则是今天讨论内容的整理。
