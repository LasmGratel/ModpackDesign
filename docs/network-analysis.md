# 把配方表画成一张图

## 为什么要把配方变成图

整合包的配方通常一层套一层。矿石经过几台机器变成金属，金属做成板和杆，板和杆又进入电路、机器外壳和工具。只看单个配方，很难看出某种材料到底有多重要，也不容易发现哪些流程是主线、哪些只是支线。

把所有物品和配方画成一张关系图，就像把一张很大的城市地图摊开来看。物品是地点，配方是连接这些地点的道路。你可以从终点往回走，看看做出终点物品要经过哪些材料；也可以从某种基础矿物往前看，看看它最后会进入哪些科技。

实际画图时，最好把“物品”和“配方”分成两种节点。比如一个配方需要铝粉、酸和催化剂，产出铝盐和副产物。图里就让三个输入都连到这条配方，再让配方连到两个产物。这样不会把一条复杂反应误画成许多互不相干的简单关系。

机器可以先作为配方旁边的说明：这条配方在哪台机器里做。需要分析机器时，再把机器也画成节点。任务书里的阶段目标也可以标在图上，比如“炼钢”“进入下一个电压阶段”“完成某种高级电路”。这样就能把配方关系和玩家实际要走的路线放在一起看。

## 先决定要分析哪条路线

配方图只会告诉你“可能怎么做”，不会自动告诉你“玩家应该做什么”。比如一个模组提供十几种发电方式，图上它们都存在；但玩家通常只会选择其中几种。若不先选一个目标，图里所有支线混在一起，最后只会看到一个特别大的网。

可以从任务书或科技门槛里挑几个阶段目标：例如第一次稳定炼钢、建立基础化工、做出某种高阶电路，或者完成终局机器。然后从目标往回找所有输入。找到配方之后，再继续追这些输入从哪里来，直到回到矿物、世界资源或开局就能拿到的东西。

任务书是一个很好的起点，但不能完全相信任务书就是主线。有时任务写了某个物品，却能用另一个配方绕开；有时任务没写某种材料，玩家却必须先做它才能继续。最好实际检查每个阶段目标：如果拿掉某个材料或机器，还有没有成本合理的办法到达目标？如果没有，它就是实际门槛，即使任务书没说。

## 用几个简单问题读这张图

第一，**要走几步？** 从基础资源到目标物品，中间有多少次转换？这能帮你找到特别长的链。但步骤多不一定就是坏事，还要继续看每一步有没有意义。

第二，**哪些东西被反复用到？** 如果一种材料出现在很多主线配方里，玩家很可能需要稳定生产它。比如一种塑料既要做电线绝缘层，又要做电路板和机器外壳，它就不是只用一次的小材料。若这些需求都靠玩家手搓，路线后面可能会很痛苦。

第三，**有没有只有一条路的瓶颈？** 假设终点需要钛，而所有钛配方都要先做同一种昂贵化学品，那么这条化学品生产线可能就是单点瓶颈。如果还有另一种能绕过它的配方，玩家就有选择。图能把这种“只有这条路能过”的情况显示出来。

第四，**某台机器到底用几次？** 一台机器若只为一个支线物品服务，可能是有意设计的特色设备，也可能是可以合并的重复设备。若一台机器承载很多关键配方，它可能是整个工业系统的核心，也可能会成为产能瓶颈。需要看它在流程中的实际位置，不能只数机器有多少条配方。

## 给每条路线加上“玩家要动几次手”

光看物品和配方，还看不出玩家到底要忙多久。同样是做一百个零件，手搓一百次、把材料放进机器等它加工、接好产线让它自己补料，配方可能完全一样，玩家的体验却差很多。

可以先用一个很简单的分法：**手动做，玩家开销高；机器自动做，玩家开销低；接成能自己供料和收货的产线，玩家开销更低。**这里说的“开销”主要是玩家需要亲自操作和盯着的次数，不是游戏里经过了多少分钟。

### 手动做：每多做一份，玩家通常都要再忙一次

手搓一件物品，玩家要拿材料、打开合成、取出成品；如果中间有很多层，还要一层层重复。比如做一台机器需要十个马达，每个马达又要线圈、导线和外壳，玩家可能不是点一次“合成”就结束，而是要来回切配方、整理背包、补材料。即使配方树只有几层，操作起来也可能很累。

所以手动路线的麻烦通常会跟数量一起增长。只做两三个零件时，手搓很方便；要做几百个时，重复操作就会变成主要成本。分析时可以记下“这条路线要玩家重复做多少次”，而不只记配方经过几台机器。

### 机器自动做：先设置，之后少操心

把材料放进机器，机器会自己加工，这已经能省下很多重复点击。但玩家通常还要自己准备输入材料、取走输出、处理副产物，或者偶尔回来补充燃料。机器能减少每件物品的操作，却不代表整条流程已经完全自动。

比如一台电炉可以自动烧一批金属，但玩家仍要自己把矿锭搬过去，烧完再拿出来。如果玩家要做十个机器，这种方式已经比手搓轻松；如果要长期做几百个，还得不断往返搬运，操作负担仍然不低。

### 被动产线：做好之后，东西会自己流过去

把供料机器、加工机器、管道或传送带、存储接在一起，材料就能从原料一路走到成品。玩家建好以后，不需要每做一件就回来点一次机器。只要原料和电力没有断，产线就能继续生产。这是玩家亲自操作最少的一类方式。

“被动”不等于完全免费。玩家前面要花时间造机器、安排空间、接物流、解决供电，还要确保输入材料跟得上。产线也可能堵住、缺料或产出堆满。区别在于这些成本大多发生在建设和维护时，而不是每生产一件都要重复付出。

## 同一条路线，做一件和做一百件不是一回事

假设玩家只需要一个催化剂。它的配方可能很长，但最后只做一次。为了自动化它，玩家可能要先造三台专用机器、接好管道、准备电力。这个时候手搓虽然麻烦，仍可能比搭完整产线省事。

再假设玩家要做五百根导线。手搓第一根不难，可每根都要重复拿铜、拉线、整理材料。此时一条导线产线虽然前期更费工，但之后反复生产会轻松许多。数量越大、未来需求越多，自动化越容易值得。

可以把比较方式说得很朴素：手搓的总麻烦，大致是“做几次，就重复忙几次”；自动化的总麻烦，大致是“先搭一次，之后偶尔补料和维护”。如果只做一件，手搓可能划算；如果长期要做很多件，产线可能划算。具体分界会受配方、基地布局和玩家工具影响，不必强求一个适用于所有整合包的固定数字。

## 把这种差别记进配方网络

在配方图里，除了记录“需要什么、产出什么”，还可以给路线加几项简单备注：手动做一批要重复几次操作；机器加工是否要玩家搬运；产线是否能自动供料和收货；搭建这条线要先花多少材料和空间；之后多久需要玩家回来补料或处理堵塞。

这样一来，分析路线时就不只是问“它有几层”，还可以问“玩家要亲手介入几次”。两条配方路径即使长度相同，如果一条每一步都要手工搬运，另一条能连续生产，后者对玩家就轻松得多。反过来，一条很短的路线如果每次都要玩家亲自切机器、换配方，也可能比看起来更费劲。

这也能帮助判断一件东西应该让玩家手搓还是自动化。高频材料应当有机会逐渐接成产线；只用一次的零件不一定值得建专机；产量很大的核心材料则最好早点让玩家看见自动化的办法。路线图因此能说明的不只是“东西怎么做出来”，还包括“玩家要为它操心多久”。

## PageRank 和聚类能帮什么忙

像 PageRank 这样的算法，可以大致找出“经常被其他重要节点依赖”的物品。直觉上，它有点像看一个人是不是经常出现在许多重要路线中转的位置。结果可以帮你发现某些看起来不起眼、其实很多流程都用到的材料。

但 PageRank 不能直接等于“主线重要度”。催化剂可能被一百条配方引用，可每次只要一份；某个控制器可能只出现在一条配方里，却是进入终局的唯一门槛。所以算法只能提供线索。还要问：玩家要消耗多少？能不能替代？它是不是主线目标的前置？

聚类算法则可以把关系密切的材料和配方分成几块。比如一块主要处理铝，一块主要处理塑料，另一块主要处理电路。设计者可以检查这些块是不是玩家能理解的“生产区域”。如果一块只包括一台机器和一个一次性配方，它可能只是把一个步骤拆成了专用设备；如果一块有多种输入、多个产物，还能供给不同的后续流程，它就更像一条真正的产业链。

## 数字看不到的东西

图不会告诉你机器占多大地方，也不知道玩家要不要来回搬流体。地图上两步就能完成的流程，实际可能需要玩家在三个基地之间来回跑；一条有十个配方的流程，如果都能在同一条产线上连续处理，玩起来反而不一定麻烦。

图也看不出玩家是否觉得有趣。一个装备可能在网络上很边缘，却是某种小众玩法的核心；一个中心性很高的材料可能只是让玩家反复采矿和等待。因此，分析结果最好和实际游玩记录一起看：玩家在哪停下来查攻略？哪台机器建完后就没再用？哪种材料总是短缺？

做这张图不是为了算出一个“整合包分数”。它更像一张检查用的地图，帮作者找到值得回头看的地方：是不是太多支线只汇到一个材料？是不是有机器只用一次，却要求很长的前置？是不是主线目标根本没在任务书里说明？发现这些问题后，再回到具体配方和玩家体验去判断怎么改。
