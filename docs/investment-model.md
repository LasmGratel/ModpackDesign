# 玩家为什么愿意做这条产线

## 先看玩家要付出什么，再看他能得到什么

玩家做一台机器，不只是消耗配方里的材料。他还要花时间找矿、烧材料、腾地方、拉电线、处理管道，有时还要反复查配方。玩家愿不愿意做，通常取决于他觉得做完之后能换来什么。

青铜高炉就是个好例子。准备砖块和结构要花时间，但做完之后可以炼钢，钢又能做出新工具和新机器。玩家很容易理解：“我现在麻烦一点，马上就能进入下一阶段。”这类投入虽然不轻，却有清楚的回报。

再看一件普通盔甲。它的配方也许不难，但如果玩家已经有更强的电力装备，那这件盔甲就没有多少吸引力。玩家不是没看见它，而是心里算了一下：“我为什么要花材料做一个更差的东西？”配方简单不等于玩家就会做，关键还是回报够不够。

## 这里说的“风险”是什么意思

现实里说风险，通常指结果不确定或可能亏损。整合包讨论里，大家说“高风险”时，往往还把另一层意思放进去了：要付出很多材料、搭很复杂的线、等很久，甚至可能做完才发现不值得。

为了方便讨论四象限，下面把“风险”先当成玩家要承担的投入和麻烦；“收益”指做完后比现有办法多得到多少好处。这个好处可以是科技进度、发电量、产量、节省时间，也可以是玩法本身更有意思。真正评估时，最好把“做起来有多麻烦”和“结果有多不确定”分开看。

收益也要跟玩家现在的情况比。一个发电机面板写着很高的功率，不代表现在就值得做。如果玩家目前只需要一点电，另一台便宜机器已经够用，那么高功率暂时没有多少价值。等后面机器多起来，电不够用了，同一套发电设备就可能变成很好的投资。

## 四种路线，各自有不同用途

### 高投入、高回报：作者希望玩家认真体验的主菜

这类路线要准备很多材料、机器或产线，但做完之后确实能改变玩家的处境。青铜高炉之后可以炼钢；一套大型柴油产线如果能长期提供大量电力，就能让玩家支撑更大的工厂。玩家会愿意提前规划，因为他知道做完之后不只是多一件物品，而是能往前走一大步。

这通常是作者最该花心思设计的部分。材料可以难找，产线可以复杂，但玩家得看得出它为什么值得做。要是前面花了几个小时搭柴油线，结果电力只比煤机多一点点，或者后面马上就有更省事的方案，玩家会觉得被坑了。反过来，如果柴油线强到能让后面所有发电方式都显得没用，它又会把成长空间一次吃光。

高投入、高回报也不一定就是“主线唯一解”。它可以是作者希望玩家重点体验的内容，也可以是一个重要的长期投资。是否必做，要看有没有其他路线能合理到达同一目标。

### 低投入、高回报：甜点路线，可能顺手把主线跳过去

这类路线最容易让玩家心动：做起来不麻烦，效果却特别强。它本身未必设计错了，但如果它可以便宜、快速地解决很多原本要靠科技线解决的问题，玩家自然会先用它，其他系统就被晾在一边。

比如某个外接模组给了一台特别强的机器，玩家用很少的材料就能完成原本 GT 要花很久做的加工；或者匠魂工具早期就比整条电力工具路线都好用。玩家会想：“我干嘛还做那条长线？”这时不是玩家玩错了，而是两边的投入和回报不平衡。

如果作者就是想留一条捷径，可以让捷径有明确代价：它可能产量低、维护贵、不能处理所有材料，或者只能在某个阶段使用。也可以把它做成一种专精路线，让玩家跳过一部分内容，但放弃另一种优势。需要避免的是它什么都好、什么都便宜，还能把整条主线绕过去。

### 低投入、低回报：放在边上就行的内容

一个包里常常有很多帽子、装饰、普通工具和模组自带的小玩意儿。作者不必把每件东西都改造成重要科技，也不必让玩家都做一遍。如果它好做、作用小、和主线也没关系，那就让它当边缘内容，玩家想玩就玩，不想做就跳过。

边缘内容也可以有意义：有人喜欢收集，有人喜欢换外观，有人会为了某种特殊玩法专门做一件工具。只是不要一边把它当可选内容，一边又让它变成一条昂贵主线的隐藏前置。玩家最不喜欢的情况之一，就是花了很多时间做一个看起来没用的东西，后来才发现不做它就过不去。

整合包也不需要把所有模组都拧成一条大麻花。有些内容可以完整保留原来的玩法，只作为额外选择。重点是让玩家知道哪些东西值得投入，哪些东西只是放在那里供感兴趣的人尝试。

### 高投入、低回报：极限挑战，或者卡住时的后备路线

正常情况下，这种路线不划算。玩家要花很多时间和材料，得到的效率却一般。有人会为了挑战自己去做它，比如坚持纯 GT 玩法，哪怕装备提升有限，也愿意把整套装备做出来。这时回报不是“单位材料换到最强属性”，而是完成挑战本身。

另一种情况是应急路线。比如玩家在 TFC 里一直找不到镍矿。正常路线当然是找到矿脉再开采；但如果运气不好，游戏可以提供一条额外办法：养蜂、处理矿泥，或者用大量低价值原料慢慢凑出镍。平常看，这条路又慢又费工；真找不到矿时，它就很有用，因为玩家至少还能继续玩下去。

所以这类路线不能只按“平时划不划算”来判断。它可能在一般情况下回报低，在玩家被资源卡住时却变得重要。好的后备路线应当确实能解决问题，但效率低于正常路线，这样它能救急，却不会让所有人都放弃找矿、直接去养蜂。

## 四象限不是永久标签

一条路线属于哪个象限，会随游戏阶段和玩家处境变化。柴油发电前期可能太贵，玩家只需要一点电；到后期持续扩厂时，它可能是很值得的核心投资。矿泥提镍平常效率很低，找不到矿时却可能是唯一能继续推进的办法。

比较两条路线时，至少要说明：玩家处在哪个阶段、手上有什么资源、目标是做几件还是长期量产、还有哪些替代办法。否则“这东西高收益”可能只是因为没说清楚比较对象。

## 还要单独问一句：它是不是必做

成本和收益之外，还有一个问题：不做它，能不能继续？如果某条路线是唯一通道，它就是必经门槛；如果还有别的办法，它才是真正的可选投资。

高投入、高回报的内容可以是主菜，也可以是可选的大型投资。高投入、低回报的路线可以是极限挑战，也可以是资源卡住时的后路。低投入、高回报的捷径可以给玩家方便，但要小心它把其他内容全跳掉。低投入、低回报的东西则完全可以留在边上。

这个四象限不是为了给配方判刑，而是帮作者想清楚：“我希望玩家把这条路当成什么？”想清楚之后，才知道应该让它更便宜、给它更多回报、设成可选，还是干脆不要让它进主线。
